## 🚀 Mise en ligne sur GitHub Pages (GRATUIT)

### Étape 1 — Créer un compte GitHub
1. Aller sur [github.com](https://github.com)
2. Cliquer **Sign up**
3. Choisir un username (ex: `ovanel-adiembo`)
4. Valider l'email

### Étape 2 — Créer le repository
1. Cliquer **New repository** (bouton vert)
2. Nom du repo : `ovanel-adiembo.github.io` (EXACTEMENT ce format)
3. Cocher **Public**
4. Cliquer **Create repository**

### Étape 3 — Uploader les fichiers
1. Cliquer **uploading an existing file**
2. Glisser-déposer TOUS les fichiers du portfolio :
   - `index.html`
   - `style.css`
   - `script.js`
   - `cv-ovanel-adiembo.pdf`
   - `certification-pix.pdf`
   - `projet-wazuh.pdf`
   - `projet-radius.pdf`
   - `Tableau_Synthese_E5_ADIEMBO_Ovanel.pdf`
   - Toutes les images (`img_*.jpg`)
3. Cliquer **Commit changes**

### Étape 4 — Activer GitHub Pages
1. Aller dans **Settings** du repo
2. Cliquer **Pages** dans le menu gauche
3. Source : **Deploy from a branch**
4. Branch : **main** → **/ (root)**
5. Cliquer **Save**

### Étape 5 — Accéder au site
Après 2-3 minutes, ton site est en ligne à :
**https://ovanel-adiembo.github.io**
